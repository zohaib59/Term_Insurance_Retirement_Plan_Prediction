# Term_Insurance_Retirement_Plan_Prediction
This dataset simulates real-world scenarios in the Indian insurance market. It is built with actuarial logic, inflation adjustment, and policy charges deduction to mimic how platforms like PolicyBazaar and ICICI Lombard calculate premiums and retirement corpus.
I’ve built a 100,000-row dataset trained on actuarial logic, inflation, and policy charges — the same principles used by PolicyBazaar and ICICI Lombard.

Key Features:
100,000 rows of clean, domain-aligned data.
Variables include Age, Retirement Age, Monthly Income, Monthly Investment, Policy Type, Coverage Amount, Premium, Expected Corpus (Gross & Net), Return Rate, Inflation Rate, Charges Rate.
Dependent Variables: Premium & Expected Corpus (Net).
Accuracy: ~99.99% prediction on training, ~99% on testing.

Use Cases:
Premium prediction models.
Retirement corpus projection.
Insurance advisory systems.
Financial planning tools.
